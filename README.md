# SWEEPER B

A_SWEEPER をベースにした B 版プロトタイプ。

## B版で直した点
- チップを 3列 × 2行のコンパクトUIに変更。スマホ画面で6枚をまとめて操作可能。
- チップ選択を pointerup ベースに変更し、iPhoneのタップ操作で確実に選択できるよう修正。
- 攻撃範囲を前後左右の直線3マスに統一。斜めは不可。
- バトルフィールドのプレイヤー表示をキャラクター選択用の立ち絵から分離。
- レン／カイはモーション資料から切り出した2Dドット素材を使用。
- IDLE / MOVE / ATTACK / OVERBLADE / ACCEL STEP を実際のゲーム内モーションとして再生。
- 「意味のない攻撃モーション画像」の固定表示を廃止し、実際に行動したときだけ2Dモーションを再生。
- チップ画像は送付されたチップデザインを使用。
- ルート直下のみで構成。サブフォルダは使用しない。
